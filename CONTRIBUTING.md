# Contributing

Orca Commander is developed privately and published here as reviewed source
snapshots. Public issues and code proposals are welcome; they are reviewed
inputs, not automatic acceptance or a promise of support for an unverified path.

For bugs, describe the expected and actual behavior, reproduction steps, source
version, platform and Orca host version. For an external reference, link the
original source and distinguish your observation from an inference or idea.
Never attach pairing QR material, credentials, live host logs or unrelated owner
content. Follow [SECURITY.md](SECURITY.md) for sensitive reports.

For code proposals, explain the behavior change and relevant checks. Preserve
exact target/request binding, explicit human confirmation, durable uncertainty
fences and the prohibition on automatic mutation replay. A status label or model
output is never permission to approve an action. Do not silently upgrade frozen
vendor pins or change application/store identities.

Run the checks in the README. A desktop CI pass does not substitute for device,
audio, accessibility, power-loss or network-transition evidence. Report original
failures and skipped checks rather than relabeling them as passes.

Maintainers evaluate and implement changes privately, then publish a verified
change with its scope and limitations. A public commit does not expose internal
PRs or conversations. Keep original MIT notices and the separate third-party
notices with redistributed material.
